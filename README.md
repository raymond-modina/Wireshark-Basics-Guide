# Wireshark Basics & Network Traffic Investigation

![Wireshark](https://www.wireshark.org/assets/images/wireshark-logo.png)

A practical **Wireshark learning and packet-analysis guide** covering the fundamentals of capturing, filtering, dissecting, navigating, and investigating network traffic.

This repository is designed for beginners who want to understand Wireshark and gradually develop the skills needed for **network troubleshooting, cybersecurity, SOC analysis, and incident investigation**.
